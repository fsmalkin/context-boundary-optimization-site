Date: 2026-08-09

The page uses navigation, hierarchy, action labels, diagrams, and destination
cards as the primary carriers. Prose remains only where it defines the product,
distinguishes API, MCP, and CBO, explains a non-visible operating consequence,

## Visual-craft gate

`npx impeccable detect mocks/open-source-product` exits clean. The final pass
keeps hover text on its accessible base color and strengthens the underline,
uses a neutral offset page shadow, replaces the generic UI-font stack with the
project's printed display stack, returns long labels to mixed case, and folds
standalone kickers into headings. Each HTML file carries one scoped
`cramped-padding` waiver: the paper shell deliberately delegates insets to its
header, main, and footer, while painted accent sections and cards define their
own internal padding.

## Verdict

All retained strings either enable a destination, define a product object that
needs prose, state a non-visible operating consequence, or
preserve a maturity and evidence boundary. The candidate selection pass should
carry the marked cuts and category tightening into the selected direction while
preserving the three intentionally distinct stories for Fred's pick.
